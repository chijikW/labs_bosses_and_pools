## Лабораторная работа №1: Основы 3D-графики

### Вариант 7 — Тор

**Цель работы:** познакомиться с основами 3D-графики: построением простых
3D-объектов, проекцией на 2D-плоскость, работой с матрицами перспективы,
ортографической проекции и аффинными преобразованиями.

**Задание:** реализовать отображение **тора** — параметрической 3D-фигуры,
образованной вращением окружности вокруг оси, лежащей в её плоскости.
Фигура должна корректно отрисовываться с учётом проекции и иметь возможность
взаимодействия с пользователем в реальном времени.

### Реализованные дополнительные задания

- [x] **1.** Переключение матрицы проекции (ортографическая / перспективная)
      через чекбокс «Perspective» в ImGui.
- [x] **2.** Изменение позиции, поворота и масштаба тора через элементы
      интерфейса (`DragFloat3` для Position, Rotation, Scale).
- [x] **3.** Анимация тора по круговой траектории с возможностью паузы
      и воспроизведения, регулировки скорости и радиуса траектории
      (`Checkbox Playing`, `Slider Speed`, `Slider Radius`).
- [x] **4.** Изменение цвета фигуры через `ColorEdit4` (параметр «Tint»).
- [x] **5.** Процедурные цвета вершин: цвет каждой вершины вычисляется
      по её локальным координатам через синусы, а выбранный в интерфейсе
      цвет умножается на процедурный.
- [ ] **6.** (на оценку 5) Отрисовка более одного объекта с использованием
      нескольких наборов дескрипторов (`VkDescriptorSet`).

### Как собрать и запустить

**Требования:** C++20, Vulkan SDK, CMake 3.20+, Visual Studio 2022 (на Windows).

**Настройка и сборка** (в любом терминале):

```bash
cmake --preset msvc-debug
cmake --build build-msvc-debug --parallel
```

**Запуск из корня проекта.**

На Windows (PowerShell):

```powershell
.\build-msvc-debug\Debug\vulkan-starter-app.exe
```

На Linux/macOS (bash):

```bash
./build-msvc-debug/Debug/vulkan-starter-app
```

**Важно:** запускать приложение нужно **из корня проекта** — иначе шейдеры
(`shaders/torus.vert.spv`, `shaders/torus.frag.spv`) не найдутся по
относительным путям.

### Управление

- **ЛКМ + перетаскивание в окне «Torus controls»** — управление ползунками.
- **Perspective** — переключение проекции.
- **Position / Rotation / Scale** — аффинные преобразования тора.
- **Tint** — множитель цвета.
- **Playing / Speed / Radius** — управление анимацией.

# 🌋 Vulkan Starter App

## С чего начать

Перед сборкой проекта вам нужно установить компилятор C++, Vulkan SDK и CMake.

Проект использует стандарт C++20, поэтому требуется один из следующих компиляторов:

- GCC 10.X
- Clang 10
- Microsoft Visual Studio 2019

Официально проект протестирован на *Windows* и *GNU/Linux*, поддержки *macOS* пока нет.
Если у вас есть рабочее решение для macOS — отправьте PR, чтобы другие тоже
могли собрать этот пример без лишних сложностей!

<ins>**1. Скачивание репозитория**</ins>

Начните с клонирования репозитория командой:

```bash
git clone --depth 1 https://github.com/vladeemerr/vulkan-starter-app
```

В этом репозитории нет подмодулей — вместо них используется механизм CMake `FetchContent`.

<ins>**2. Настройка проекта**</ins>

Выполните одну из команд CMake, чтобы скачать зависимости и настроить проект:

```bash
cmake --preset debug       # для GNU/Linux (GCC/Clang)
cmake --preset msvc-debug  # для Windows (Visual Studio 2019)
cmake --preset mingw-debug # для Windows (MinGW)
```

Если хотите собрать в режиме `release`, замените `debug` на `release`.

Если вы что-то добавили или удалили (файлы), либо хотите перегенерировать файлы проекта,
снова выполните команду выше.

<ins>**3. Сборка**</ins>

Чтобы собрать проект, используйте команду ниже. Скорее всего, вы используете
пресет `debug`, поэтому директория, в которую попадут файлы сборки, называется `build-debug`.

Аналогично для `release` эта директория будет называться `build-release`.

Выполните одну из этих команд — в зависимости от выбранного пресета:

```bash
cmake --build build-debug --parallel   # для debug
cmake --build build-release --parallel # для release
```

### Запуск

После успешной сборки в директории `build-*` появится исполняемый файл в одной из подпапок.

Для сборок `msvc-{debug|release}` выходная подпапка называется `Debug` или `Release` соответственно.
Для остальных конфигураций выходная подпапка называется `vulkan-starter-app`.

**Убедитесь, что рабочая директория установлена в корень проекта!**
Корень проекта — это место, где лежит этот README-файл. Иначе код,
отвечающий за загрузку шейдеров и других ресурсов из файлов, не сработает,
потому что используются относительные пути.

### Компиляция шейдеров

В `CMakeLists.txt` есть рецепт сборки для компиляции шейдерных файлов
вместе с приложением. Найдите комментарий в этом файле, чтобы увидеть,
как компилировать ваши шейдеры.
